## agla-dev-tools v0.1.1

This release improves command-line tools and the development setup.

### Changes

- Add `rimraf` wrapper scripts for POSIX and Windows.
- Add support for the Anthropic `fable` model in the commit message hook.
- Update CI workflows and development dependencies.
- Require Node.js 24 or later and pnpm 12 or later.
